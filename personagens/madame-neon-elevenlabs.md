# Madame Neon – Falas para o ElevenLabs (vídeo 03)

## Passo a passo
1. **Voices → Create a Voice → Voice Design.** Cole o prompt de voz de `madame-neon-flow.md` (seção "Voz alternativa"). Gere, escute as 3 opções e salve a melhor como **"Madame Neon"**.
2. **Text to Speech**: escolha a voz "Madame Neon" e o modelo **Eleven v3** (aceita as tags entre colchetes, como `[sarcastic]`). Se preferir o **Multilingual v2**, apague as tags.
3. Configuração inicial:
   - v3: Stability em **Natural**.
   - v2: Stability 45 %, Similarity 80 %, Style 30 %, Speaker Boost ligado.
4. Gere **uma fala por vez**, com um arquivo por clipe (`01.mp3`, `02.mp3`...). Assim fica fácil gerar de novo só a fala que saiu ruim.
5. No CapCut, coloque cada áudio sobre o clipe correspondente do Flow.

## Clipes no Flow sem fala
No prompt de cada clipe, troque a fala por:
```
She talks to the camera with natural mouth movement, no audible dialogue. Only ambient sound: distant traffic and soft synthwave music.
```
A boca não vai bater perfeitamente com o áudio. Duas saídas:
- **Simples:** durante a fala, mostrar mais as cartas e as mãos dela. Quando o rosto aparecer, a diferença quase não se nota.
- **Melhor:** passar cada clipe com o áudio por uma ferramenta de lip-sync (ex.: Sync Labs ou HeyGen) antes de editar.

## Falas
**01 – Gancho**
```
[slow, knowing] Setz dich, Baby. [short pause] Ich lege dir drei Karten. Eine davon betrifft genau dich.
```

**02 – Interação**
```
Schreib eine Zahl in die Kommentare: eins, zwei oder drei. [playful] Die Karten warten nicht.
```

**03 – Karte 1 (parte 1)**
```
[dramatic] Karte eins: Der Wagen. [amused] Du willst los, und zwar sofort.
```

**04 – Karte 1 (parte 2)**
```
[sarcastic] Aber Baby... erst schauen, dann Gas geben. Diese Woche lohnt sich ein Umweg.
```

**05 – Karte 2 (parte 1)**
```
[dramatic] Karte zwei: Die Liebenden. [laughs] Nein, nicht das, was du denkst. Es geht um eine Entscheidung.
```

**06 – Karte 2 (parte 2)**
```
Zwei Wege, beide sehen gut aus. Hör auf dein Bauchgefühl... [short pause] [dry] nicht auf das Radio.
```

**07 – Karte 3 (parte 1)**
```
[dramatic] Karte drei: Die Sonne. [warmly] Endlich mal gute Laune auf meinem Tisch.
```

**08 – Karte 3 (parte 2)**
```
[softly] Irgendwas wird diese Woche leichter. Kein Versprechen... nur ein bisschen Licht zwischen den Palmen.
```

**09 – Auflösung**
```
Und welche betrifft dich? [teasing] Die, bei der du gerade gegrinst hast. [chuckles] Ich hab's gesehen.
```

**10 – Abschluss**
```
Schreib mir deine Karte und folge mir. Unterhaltung, keine Vorhersage. [sarcastic] Ich hab' schließlich einen Ruf zu verlieren.
```

## Dicas
- Se ela falar rápido demais, coloque "..." nos pontos onde quer pausa.
- Se alguma palavra sair com sotaque estranho, escreva de outro jeito só para a pronúncia (ex.: "Baby" → "Bäibi").
- O som ambiente (trânsito, sirene, synthwave) vem dos clipes do Flow ou de um som do CapCut, não do ElevenLabs.
